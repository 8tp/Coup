# Arabic (`ar`) glossary

Modern Standard Arabic for players in the UAE, Saudi Arabia, Iraq, Jordan and
Egypt: no single country's dialect, kept light where the English is light.
No Arabic edition of Coup was found (a web search turned up only English
editions and fan descriptions), so every term below is our choice. The
descriptions Arabic sites give of the game already use most of these words
(الدوق، القاتل، السفير، الخزينة، المساعدة الخارجية، التحدي، الانقلاب),
which raises confidence for those.

Confidence: **high** = the obvious word, **medium** = a choice between good
options, **low** = a native speaker should confirm.

## Characters

Names carry the article (`الدوق`), because they appear as definite nouns in
almost every sentence and on the card plates. Messages never glue a prefix
(بـ، لـ) onto a name, because names render as separate nodes (with an emblem
in the log) and a joined letter would break; "Block with X" is
`صد بصفة X` ("block as X").

## Modes and factions

| English | Arabic | Note | Confidence |
|---|---|---|---|
| Classic | الكلاسيكي | | high |
| Reformation | الإصلاح | Sentences say توسعة الإصلاح ("the Reformation expansion") so it is not read as "repair". The FAQ adds (Reformation) for search | medium |
| Loyalist | أهل الولاء | Seat tag ولاء, mark ▲ ولاء | low |
| Reformist | أهل الإصلاح | Seat tag إصلاح, mark ◆ إصلاح | low |
| faction | فصيل | | high |

Faction names were the hardest choice. A sound plural (الموالون، الإصلاحيون)
changes its ending with grammatical case, which a fixed param cannot do.
الموالاة carries a strong pro-government meaning in Syrian and Lebanese
politics, and الموالي has an unfortunate historical sense. `أهل X` ("the
people of X") never changes form, works in "من أهل الإصلاح" ("a
Reformist"), "إلى أهل الولاء" ("to Loyalist") and as a label, and pairs the
two sides.

## Register and gender

- **The reader.** One register throughout: plain MSA, addressing the player
  directly, but in forms that are written the same for a man or a woman. Arabic
  imperatives (اختر / اختاري) and present-tense second-person verbs (تخسر /
  تخسرين) show gender, so the text avoids them:
  - buttons and instructions use the verbal noun: تحدٍّ، تمرير، إنشاء غرفة،
    اللعب ضد البوتات، عليك التخلي عن ورقة، يكفي لمس حركة، المطلوب: …;
  - "you can / you must" is يمكنك / عليك + verbal noun; "you have" is لديك / معك;
  - past tense and conditionals with the past are written the same for both
    (خسرت، فزت، إن شككت … خسرت ورقة), so outcomes and rules use them;
  - "you need" is يلزمك.
  This also covers the main buttons (اللعب ضد البوتات، جولة جديدة) and the SEO
  text. Any masculine form addressed to the reader is a slip, not a policy.
- **Other players.** Third-person Arabic verbs always show gender, and a
  player's gender is unknown. Where a neutral phrasing reads just as well it
  is used (دور X، على X خسارة ورقة، لدى X الدوق، الدور الأول من نصيب X، ليس مع X
  الدوق). Elsewhere the masculine is used as the grammatical default
  (ادّعى X، فاز X، يستهدفك X). This is the normal convention in Arabic
  software, but a woman named Sara will read "ادّعى سارة".
- **Bots** are masculine (بوت is masculine), so the personality descriptions
  read يخادع، يتحدى.
- **Numbers.** Western digits, as the app formats them. Counts use all six
  Arabic plural forms: one = noun + واحد/واحدة or the noun alone, two = the dual
  (عملتان / عملتين by case, with no digit), 3–10 = digit + plural (3 عملات),
  11–99 = digit + singular with accusative ending (11 عملة، 11 لاعبًا), 100+
  and 0 = digit + singular.
- **Punctuation.** Arabic comma (،) and question mark (؟), guillemets « »
  for button names quoted in text. No exclamation marks except the chat phrase
  كذب! (the English has "Liar!").
