# Simplified Chinese (zh-Hans) glossary

Written for mainland players. The game circulates in China as 《政变》 (also
sold and discussed as 《政变疑云》, and in Taiwan as 《政變》/《政變疑雲》).
Character and action names follow the names mainland players use for the
Chinese edition, checked against Chinese rule write-ups (WING 桌游
cn.wingboardgame.com, zhiyanjia.com, andyventure.com for the Taiwan edition).
Nobody who speaks Chinese natively has reviewed this yet.

Confidence: **high** = matches the published/played name; **medium** = common
but variants exist; **low** = my choice, no established name found.

随机 (Random), 激进 (Aggressive), 保守 (Conservative), 记仇 (Vengeful, "holds a
grudge"), 狡诈 (Deceptive), 推理 (Analytical), 高手 (Optimal, "expert": 最优

## Register and conventions

- **Address:** 你 throughout (informal, the norm for games). No 您.
- **Gender:** player names have unknown gender, so no 他/她. Sentences use the
  name again, 对方 ("the other player"), 该玩家, or are built without a pronoun.
- **Punctuation:** full-width Chinese punctuation （，。：；“”《》）; ASCII only
  inside numbers ("2/3", "+2") and around Latin text. "·" separates facts
  as in English. No exclamation marks except in the quick chat line 骗子！
- **Spacing:** a half-width space between Chinese and Latin letters or digits
  ("勒索了 2 枚金币", "Coup Online 是", "轮到 Alice 了"), none next to
  full-width punctuation. Player names are params: where a name param can be
  the reader (who is shown as 你, which takes no spaces), the message uses a
  `you` select only to place those spaces:
  `{actor, select, you {你} other {{actor} }}`. Character, action and faction
  names are Chinese and take no spaces.
- **Plurals:** Chinese has the single CLDR category `other`. Where English
  says something different for exactly one, the message uses `=1`.
- **Numbers:** always with a classifier: 枚 (coins), 张 (cards), 名 (players,
  opponents), 次 (times), 个 (bots, turns).
- **Game name:** "Coup" and "Coup Online" stay in Latin letters; the local
  name is added as Coup《政变》 in the About text, rules overview, tutorial
  title and SEO fields. The tab title stays "Coup ABCD".
